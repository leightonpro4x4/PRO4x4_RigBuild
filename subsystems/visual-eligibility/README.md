# visual-eligibility

Stage 5 adapter consumes canonical decisions and maps exact Alpha93 mesh identities to approved, preview, unavailable or blocked states. It does not add products or evaluate commercial dependencies. Every current Ranger asset is preview-only; no approval records are supplied. Future trusted production records must bind vehicle, filename and exact hash with an explicit approval record ID. Successful loading never grants approval.

Placement compatibility is distinct from commercial fitment: the preserved Rally mesh requires the Predator mounting assembly, and the preserved lights require the Predator/Rally assembly. Other commercially selectable routes (including Toro) have no matching asset and remain visually unavailable. This rule suppresses unsupported mesh placement; it never inserts a hoop into WF2's dependency graph.

Factory front/rear visibility is independently derived from the corresponding eligible replacement. Blocked builds and unavailable Y62 bases expose no fabricated fallback. No Y62 production base is created or promoted.
