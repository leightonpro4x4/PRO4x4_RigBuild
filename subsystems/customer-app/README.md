# customer-app

Stage 5 app.mjs connects the single public/index.html entrypoint to the shared domain session and Ranger renderer. Authoritative catalogue mode is the default. Explicit Alpha93 checkpoint mode preserves the seven-product regression and A$10,239 fixture. Separate versioned local selection keys prevent fixture state entering catalogue mode. Restoration recomputes canonical decisions; stored render/approval state is never trusted.

Powerboards remains disabled in catalogue mode. Known/unpriced totals are separated. Y62 exposes catalogue selection without any 3D fallback. A checkpoint can be saved locally; no production quote service, persistence backend or delivery exists.
