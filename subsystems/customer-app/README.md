# customer-app

app.mjs connects the single public/index.html entrypoint to the shared domain session and Ranger renderer. Authoritative catalogue mode is the default. Explicit Alpha93 checkpoint mode preserves the seven-product regression and A$10,239 fixture. Stage 6 projects.mjs adds WF1-style project saves, immutable revision navigation, dirty guards, handoff receipts, shares and quote initiation over the server APIs.

Powerboards remains disabled in catalogue mode. Known/unpriced totals are separated. Y62 exposes catalogue selection without any 3D fallback. Browser storage caches unsaved UI selections and a server project/revision pointer only. Loading a saved project fetches canonical server data; clean saved rendering and calculations use that response. Cached pointers cannot bypass ownership and stale revisions require explicit migration.

Save/new-project/reload/revalidate actions are explicit. Dirty or unsaved builds cannot start a quote or share. The server returns a pinned quote receipt, with review/pricing state; customer input cannot finalise or override totals. Alpha93 legacy imports require an explicit confirmation and remain checkpoint-only. Server quotes replace the old local quote snapshot button; external quote delivery is not connected in this stage.
